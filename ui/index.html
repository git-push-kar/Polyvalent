How it works

The run is replayed sample by sample (3 min of plant time each). The trained detector scores overlapping sensor windows. Consecutive alarms confirm an event. When the event closes, the classifier evaluates its evidence and the adapter can write a root-cause report. The selected fault ID only chooses the input run.
