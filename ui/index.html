How it works

The run is replayed sample by sample (3 min of plant time each). The detector scores every sample against a fault-free baseline; after several consecutive alarms an event is confirmed and its structured evidence is routed through Laya to the TEP anomaly adapter, which writes the root-cause report. The model only ever sees the evidence, never the raw series.
